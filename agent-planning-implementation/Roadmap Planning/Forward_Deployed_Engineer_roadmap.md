# Forward Deployed Engineer Skills Checklist

A 100-skill, category-by-category checklist for becoming a proficient Forward Deployed Engineer (FDE).
Inspired by the AI Engineering Skills Checklist by Marina Wyss (https://www.linkedin.com/in/marina-wyss/).

---

## 1. Technical Foundation (7 skills)

- [ ] Basic statistics and probability intuition
- [ ] Linear algebra basics: vectors, matrices, dot products
- [ ] Understanding of APIs: REST, GraphQL, webhooks
- [ ] Familiarity with SQL and relational data models
- [ ] Command-line fluency: navigating, scripting, debugging
- [ ] Networking basics: HTTP, DNS, TLS, load balancers
- [ ] Version control with Git: branching, PRs, conflict resolution

---

## 2. Python for FDEs (7 skills)

- [ ] Writing scripts to automate repetitive tasks
- [ ] Working with REST APIs and SDKs in Python
- [ ] Parsing and transforming JSON, CSV, and XML data
- [ ] Building quick proof-of-concept tools and demos
- [ ] Fast prototyping with Streamlit and Gradio
- [ ] Using virtual environments and package management
- [ ] Writing readable code that customers and teammates can maintain

---

## 3. Software Engineering Fundamentals (6 skills)

- [ ] Reading and navigating unfamiliar codebases quickly
- [ ] Debugging with logs, breakpoints, and network traces
- [ ] Writing unit tests and understanding test coverage
- [ ] Containerization with Docker for reproducible environments
- [ ] Basic CI/CD: pipelines, build artifacts, environment configs
- [ ] Using infrastructure tools: cloud consoles, IAM, storage buckets

---

## 4. ML & AI Literacy (7 skills)

- [ ] Supervised vs. unsupervised learning at a conceptual level
- [ ] How training, evaluation, and inference differ
- [ ] What overfitting and underfitting mean in practice
- [ ] Classification and regression metrics: precision, recall, RMSE
- [ ] How foundation models and LLMs work at a high level
- [ ] Tokenization, embeddings, and vector similarity
- [ ] Knowing when ML adds value vs. when rules are sufficient

---

## 5. LLM & Generative AI Fluency (8 skills)

- [ ] Prompt engineering: structuring effective prompts
- [ ] Few-shot and in-context learning
- [ ] Retrieval-Augmented Generation (RAG) fundamentals
- [ ] Fine-tuning at a conceptual level: when and why
- [ ] Model selection: cost vs. capability vs. latency tradeoffs
- [ ] Tool use and function calling with LLMs
- [ ] Structured output: JSON mode, constrained decoding
- [ ] Hallucination risk: recognizing and mitigating it in customer demos

---

## 6. Customer-Facing Technical Skills (8 skills)

- [ ] Running live technical demos under pressure
- [ ] Translating customer requirements into engineering specs
- [ ] Explaining technical concepts clearly to non-engineers
- [ ] Building quick POCs and prototypes for customer evaluation
- [ ] Collecting feedback loops: what worked, what didn't, why
- [ ] Scoping and sizing implementation effort for customer deals
- [ ] Writing technical documentation for handoff
- [ ] Managing stakeholder expectations during integration projects

---

## 7. Integration & Deployment (8 skills)

- [ ] Integrating third-party APIs into customer workflows
- [ ] Webhooks and event-driven integrations
- [ ] Authentication patterns: OAuth, API keys, SSO/SAML
- [ ] Data ingestion pipelines from customer systems
- [ ] Deploying services on cloud platforms (AWS, GCP, Azure)
- [ ] Environment configuration management (dev, staging, prod)
- [ ] Configuring reverse proxies (Nginx/Envoy), routing, and CORS
- [ ] Troubleshooting integration failures with customers live

---

## 8. Data Skills (7 skills)

- [ ] Querying and transforming data with SQL
- [ ] Cleaning and normalizing messy customer data
- [ ] Identifying data quality issues that affect model performance
- [ ] Building lightweight ETL pipelines for onboarding
- [ ] Understanding schema differences between customer data sources
- [ ] Designing idempotent data loading scripts for enterprise cutovers
- [ ] Validating data pipelines end-to-end before handoff

---

## 9. Security & Compliance Awareness (5 skills)

- [ ] PII identification and data handling best practices
- [ ] Role-based access control (RBAC) concepts
- [ ] Common compliance frameworks: SOC 2, GDPR, HIPAA at a high level
- [ ] Secure API key and secret management
- [ ] Understanding customer security review processes (questionnaires, audits)

---

## 10. System Design & Architecture (6 skills)

- [ ] Designing simple end-to-end ML-powered workflows
- [ ] Latency, throughput, and scalability tradeoffs
- [ ] Choosing between synchronous and asynchronous architectures
- [ ] Caching strategies for high-traffic integrations
- [ ] Multi-tenant architecture concepts
- [ ] Designing for graceful degradation and fault tolerance

---

## 11. Monitoring & Observability (5 skills)

- [ ] Setting up logging and alerting for deployed integrations
- [ ] Interpreting logs and traces to find root causes
- [ ] Monitoring data and model drift in customer environments
- [ ] Dashboarding key metrics for customer success reviews
- [ ] Postmortem analysis when things break in production

---

## 12. Sales Engineering & Deal Support (7 skills)

- [ ] Participating in technical discovery calls
- [ ] Responding to RFPs and technical security questionnaires
- [ ] Building differentiated competitive technical narratives
- [ ] Leading proofs of concept (POCs) with success criteria defined upfront
- [ ] Handling technical objections from customer engineering teams
- [ ] Collaborating with AEs on deal strategy
- [ ] Transitioning customers from POC to production successfully

---

## 13. Cross-Functional Collaboration (6 skills)

- [ ] Feeding customer pain points back to product and engineering
- [ ] Writing clear internal bug reports with reproducible steps
- [ ] Advocating for customer needs in roadmap discussions
- [ ] Partnering with customer success for post-launch support
- [ ] Conducting post-launch architecture reviews and retrospective meetings
- [ ] Building internal playbooks for common customer integration patterns

---

## 14. Mindset & Soft Skills (7 skills)

- [ ] Thriving in ambiguity: building without full requirements
- [ ] Knowing when to build vs. when to configure or integrate
- [ ] Context-switching between multiple customers and projects
- [ ] Staying calm when a live demo breaks
- [ ] Writing clear async communication (Slack, email, Notion)
- [ ] Learning a new customer domain quickly (healthcare, finance, legal...)
- [ ] Balancing speed of delivery with technical quality

---

## 15. FDE Toolbox (6 skills)

- [ ] API testing with Postman or Insomnia
- [ ] Jupyter notebooks for quick data exploration
- [ ] VS Code extensions for productivity
- [ ] Benchmarking latency and token throughput tools (Locust, wrk)
- [ ] Slack/Notion/Linear for async cross-team coordination
- [ ] Screen recording and async video for customer communication (Loom etc.)

---

**Total: 100 skills across 15 categories**

> The one thing to take away: the best FDEs are generalists who go deep when it matters. You don't need to know everything � you need to know enough to build trust, unblock customers, and know when to call in a specialist.
